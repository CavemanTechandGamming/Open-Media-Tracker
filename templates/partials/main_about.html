About

Open Media Tracker is a self-hosted web application for cataloguing television and feature-film libraries on local paths. It reconciles each top-level library directory against TMDB (and TVDB when configured), presenting title and series status, artwork, and—where applicable—coverage of on-disk assets relative to provider episode rosters. Indexing is change-aware at the title-folder boundary so API usage and filesystem traversal remain bounded on large collections.
